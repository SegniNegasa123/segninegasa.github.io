Tereguwami-

9-Layer Spatio-Temporal Graph Convolutional Architecture & ONNX Edge Quantization
View Source Read Paper

Core open-source repository for Tereguwami, the Ministry of Innovation and Technology (MinT)-backed 9-layer multimodal framework for Ethiopian Sign Language (EthSL) translation. Features real-time landmark tracking, ST-GCN spatial skeletal topology modeling, sEMG signal disambiguation, and generative avatar speech-to-sign rendering.

Key Architectural Modules:

  • models/st_gcn.py: 9-layer Spatio-Temporal Graph Convolutional Network processing skeletal graph node sequences.
  • inference/onnx_quantizer.py: INT8 quantization pipeline reducing model footprint to 14.2MB for edge Android and ARM deployment.
  • sensors/semg_stream.py: DSP filtering pipeline (Butterworth bandpass, notch filter) for silent-speech muscular contraction disambiguation.
  • api/fastapi_gateway.py: Sub-50ms WebRTC & WebSocket gateway streaming synchronized 3D avatar animation vectors.
PyTorch ST-GCN MediaPipe ONNX Mobile sEMG Signals FastAPI WebRTC

BIOMIMETIC-COOLING-SIMULATION

Computational Fluid Dynamics (CFD) for Termite-Mound Passive Structural Cooling
View Source Zenodo Dataset

Scientific research dataset and simulation software investigating natural convective airflow and thermal regulation mechanisms derived from biological termite mound geometries. Published openly to Zenodo with a registered DOI for architectural sustainability and green building research in sub-Saharan climates.

Key Architectural Modules:

  • simulation/mesh_generator.py: Parametric 3D internal chimney mesh generator modeling varying solar thermal chimney aspect ratios.
  • cfd/navier_stokes_solver.py: Incompressible Navier-Stokes numerical solver modeling buoyancy-driven natural ventilation.
  • data/zenodo_bundle/: Open dataset capturing temperature gradients, velocity vector fields, and passive thermal damping factors.
Computational Fluid Dynamics Python Numerical Analysis Zenodo DOI: 10.5281/zenodo.19902133 Green Architecture

dura-schools (DuraSchools-SaaS)

Production Multi-Tenant Cloud Architecture for African Primary & Secondary Schools
View Source

The production codebase powering DURA Tech's flagship EdTech SaaS product, DuraSchools. Deployed across 7 Ethiopian boarding schools, this platform automates school administration, continuous assessment grading, offline-resilient parent SMS notifications, and financial ledger reconciliation, generating over 350,000+ ETB in commercial gap-year revenue.

Key Architectural Modules:

  • backend/tenant_router.py: Dynamic multi-tenant PostgreSQL schema isolation ensuring rigorous data privacy across separate institutions.
  • services/sms_dispatcher.py: Asynchronous Celery + Redis worker pool delivering automated academic progress SMS to parents via localized telecom gateways.
  • frontend/src/dashboards/: Responsive, lightweight React dashboards optimized for low-bandwidth 3G mobile connections.
FastAPI React PostgreSQL Redis Multi-Tenancy 350K+ ETB Revenue DURA Tech

MeskelFlow-AI

Deep Q-Networks & Edge Computer Vision for Traffic Signal Optimization
View Source View Poster

An intelligent adaptive traffic signal control framework engineered specifically for the dense, irregular traffic flows of Meskel Square and major Addis Ababa intersections. Uses real-time vehicle detection with YOLOv8 running on NVIDIA Jetson edge nodes to formulate state reward vectors for a Deep Q-Network (DQN) agent that dynamically tunes signal phase splits.

Key Architectural Modules:

  • vision/yolov8_tracker.py: Multi-class vehicle detection & ByteTrack tracking pipeline extracting queue lengths and approach speeds.
  • rl/dqn_agent.py: Double Deep Q-Network with prioritized experience replay learning optimal green-light phase switching.
  • simulation/sumo_env.py: Microscopic traffic simulation wrapper (SUMO) calibrated against empirical Addis Ababa vehicle counts.
YOLOv8 Deep Q-Networks Reinforcement Learning SUMO Simulation OpenCV Jetson Nano

Hiwot-Emergency-Triage

Decentralized Real-Time Emergency Medical Dispatch & Priority Triage Network
Repository Certification

A robust real-time emergency medical dispatch codebase designed to solve communication fragmentation during acute trauma and hospital transfers in developing urban environments. Incorporates GIS nearest-facility routing, automatic ambulance dispatching, patient severity scoring (START algorithm), and automated fallback to encrypted SMS when data networks degrade.

Key Architectural Modules:

  • triage/severity_calculator.py: Algorithmic patient vital prioritization implementing emergency severity triage scores.
  • geo/spatial_routing.py: PostGIS and OpenStreetMap spatial routing minimizing transit times to verified trauma centers.
  • telecom/sms_failover.py: Automatic fallover engine that converts packet stream drops into compressed SMS payload bursts.
